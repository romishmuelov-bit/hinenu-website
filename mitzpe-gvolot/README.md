# המרכז לחלוציות · מצפה גבולות

דף נחיתה עצמאי. נפרס תחת `/mitzpe-gvolot/`.
כל הנתיבים יחסיים, אז התיקייה עובדת כמו שהיא בלי הגדרות נוספות.

## מבנה

| | |
|---|---|
| `index.html` | הדף הראשי — סיפור גלילה ושלושת המסלולים |

## איך הגלילה עובדת

הסיפור הוא רצף תמונות שמצויר לקנבס, לא וידאו. הגלילה כותבת ערך התקדמות אחד,
ולולאת `requestAnimationFrame` נפרדת מרככת אותו (`current += (target - current) * DAMPING`)
ומציירת רק כשאינדקס הפריים משתנה. הריכוך הזה הוא כל הסיבה שזה מרגיש חלק.

שני הסרטונים מחוברים למסלול אחד עם במה דביקה אחת. נקודת החיבור היא 0.542,
והיא נופלת בכוונה בפער בין שני ביטים כדי שאף טקסט לא יחצה אותה.

הקבועים לכוונון נמצאים בראש ה-`<script>` ב-`index.html`.

## מה לא נמצא כאן

חומרי המקור לא נכנסו לריפו — הם לא נטענים בזמן ריצה, והם 60MB שגיט היה שומר לנצח:

- `assets/dune.mp4` (34MB) ו-`assets/סרטון גלילה זום אין.mp4` (17MB) — שמהם חולצו הפריימים
- `assets/1.svg`, `2.svg`, `3.svg` (8MB) — מקור הכרזות

הם נשארו בתיקיית העבודה המקומית `MitzpeGvolot`. **צריך אותם רק כדי לייצר מחדש
פריימים או כרזות**, לא כדי להריץ את האתר.

הפריימים חולצו ב-ffmpeg עם הגריידינג אפוי פנימה:

```
eq=contrast=1.13:saturation=0.86:brightness=-0.012,colorbalance=rs=0.035:gs=0.008:bs=-0.045:rh=0.045:gh=0.012:bh=-0.038
```

## מה עוד פתוח

- הטופס לא מחובר ליעד — הוא מיירט את השליחה ורושם לקונסולה
- אין קובץ אודיו, אז כפתור הרוח מוסתר
- חסרים הקישורים לעמוד היזמות ולמיטאפים בעמוד `poalim`
