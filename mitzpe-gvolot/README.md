# המרכז לחלוציות · מצפה גבולות

דף נחיתה עצמאי. נפרס תחת `/mitzpe-gvolot/`.
כל הנתיבים יחסיים, אז התיקייה עובדת כמו שהיא בלי הגדרות נוספות.
מקושר מהאתר הראשי (הכפתור "התיישבות" בהירו, מסלול ב' בסקשן המסלולים, ועוד).

## איך הגלילה עובדת

הסיפור הוא רצף תמונות שמצויר לקנבס, לא וידאו. הגלילה כותבת ערך התקדמות אחד,
ולולאת `requestAnimationFrame` נפרדת מרככת אותו (`current += (target - current) * DAMPING`)
ומציירת רק כשאינדקס הפריים משתנה. הריכוך הזה הוא כל הסיבה שזה מרגיש חלק.

## מה לא נמצא כאן

חומרי המקור לא נכנסו לריפו (`mitzpe-gvolot/.gitignore`) — הם לא נטענים בזמן ריצה, והם
עשרות MB שגיט היה שומר לנצח:

- `assets/dune.mp4` ו-`assets/סרטון גלילה זום אין.mp4` — שמהם חולצו הפריימים ב-`frames/`
- `assets/1.svg`, `2.svg`, `3.svg` — מקור הכרזות ב-`posters/`
- `assets/תמונת אמצע.png`, `assets/desktop.ini` — לא בשימוש באף עמוד

הם נשארו בתיקיית העבודה המקומית. **צריך אותם רק כדי לייצר מחדש פריימים או כרזות**,
לא כדי להריץ את האתר.
